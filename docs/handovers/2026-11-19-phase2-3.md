## 1. 本阶段目标

- 补齐相对运镜的**跟随目标**与**多段组合**。
- 把场景写入 Concat 工程文档（顶层 `scene`），并提供 MCP 场景 CRUD，使 Agent 能从零建场景并导出。

不在本阶段范围内：编辑器内场景片段/时间轴联动、检查器相机参数、图形图层素材化。

## 2. 交付内容

- `concat-camera`：`CameraMoveType::Follow`。
- `concat-scene`：
  - `MovePreset { target, offset_x, offset_y, zoom }`，`target_pose_in(scene)` 解析图层；
  - `MoveSequence`（链式相对、`pose_at_in`、`bake_in`）；
  - `Scene::add_move` / `add_sequence`；
  - 11 tests。
- `concat-studio`：
  - `load_scene` / `save_scene`（裸 Scene 与 Concat 工程文档兼容）；
  - `concat-studio save <scene.json> <project.json>`；
  - 工程文档往返测试。
- `concat-mcp`：
  - `scene_create` / `scene_add_layer` / `scene_camera_move` / `scene_get`；
  - `scene_render` 兼容工程文档；
  - e2e `an_agent_builds_and_renders_a_two_character_scene_headless`。
