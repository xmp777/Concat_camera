# 阶段交接（Handovers）

每个阶段一个文件，命名：`YYYY-MM-DD-<stage>.md`。

- 根目录 `HANDOVER.md` 只保留“当前状态 + 最新入口”。
- 阶段文件是历史记录，完成后不要重写结论；后续变化写到新阶段文件。
- 模板：`TEMPLATE.md`。
- 必填：验证证据、子代理审查结论、P0/P1 处理、已知限制、Git commit。
